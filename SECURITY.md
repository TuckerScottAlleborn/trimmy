# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub security advisories](https://github.com/TuckerScottAlleborn/trimmy/security/advisories/new),
not in a public issue.

Useful things to include: the Trimmy version (bottom-right of the open screen), your OS, and the
steps or file that trigger the problem.

## Supported versions

Only the latest release gets fixes. Trimmy offers updates in the app, so staying current is one
click on **[update]**.

## What Trimmy does and doesn't touch

See [Security](README.md#security) and [Privacy](README.md#privacy) in the README: no accounts,
no telemetry, one network request (the update check), signed updates, and FFmpeg only ever runs
on files you opened.
