what it does

  • Opens just about any video. Game clips, phone videos, screen recordings, downloads: MP4, MKV, MOV, WebM, AVI, TS, WMV, FLV and more, in H.264, HEVC, AV1 or VP9.
  • Four ways in: drag it onto the window, paste its path, browse (Ctrl+O), or right-click it and pick Open with.
  • Shows the waveform, so you can see where the shot, the kill or the shout is.
  • Exports in about a second with zero quality loss, because it doesn't re-encode.
  • Keeps every audio track, so game audio and your mic both come through.
  • Never touches the original. Your clip is saved next to it as name_trimmed.mp4.
  • Stays on your PC. Nothing gets uploaded, there's no telemetry, and it works offline.

what it doesn't do

faq

Is it really free?

Yes, all of it. There's no login or sign-up, no paid features or pro version, no subscription, no trial, no ads, and no watermark on your clips. Trimmy is open source under the MIT license.

Does trimming lose quality?

No. Trimmy copies the original video and audio into the new file as they are (an FFmpeg stream copy) instead of re-encoding them. That's also why it only takes a second.

Why does the start handle snap?

A stream copy can only start on a keyframe, so the start handle snaps to them (the faint ticks under the timeline), and the preview starts exactly where your clip will. ShadowPlay puts one about every second; OBS's default settings, up to every few seconds. The end handle doesn't snap. A frame-exact mode is on the roadmap.

Is there a Mac or Linux version?

There's a macOS build for Apple Silicon and Intel (macOS 11 or later), but nobody has tried it on a real Mac yet. The macOS notes say how to open it (download the .dmg); please report back either way. No Linux build yet.

Is the download safe?

The installers are built from the public source code by GitHub Actions and attached to the GitHub release, which lists each file's SHA-256 checksum. Windows warns only because Trimmy isn't code-signed yet.

What does Trimmy send over the network?

Almost nothing. It doesn't collect, store or send anything about you or your videos, and your files never leave your computer. The only request it makes is the update check: when it starts, it asks this project's GitHub releases whether there's a newer version. Like any web request, that shows GitHub your IP address. An update is downloaded only when you click [update].

code signing policy

Windows releases are to be signed through the SignPath Foundation's free program for open-source projects: free code signing provided by SignPath.io, certificate by SignPath Foundation. This applies from the first release after the project is approved; earlier releases are unsigned.

Only binaries built from this project's source code by its release workflow are signed. Committer, reviewer and release approver: Tucker Scott Alleborn, with two-factor authentication. Nothing is sent from your computer without your consent, apart from the update check described in the privacy answer above.
